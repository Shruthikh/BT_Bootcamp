# Personal Learning Dashboard (PLD)

## Framework Used
Bootstrap 5

## Responsive Strategy
Mobile-first design using Bootstrap grid system.

## Browser Testing
Tested successfully on:
- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari

## Features
- Login UI (UI only)
- Dashboard with Module → Unit → Topic hierarchy
- Lab progress tracker
- Profile page with image and skills
- Responsive static image gallery
- Cross-browser compatible UI
